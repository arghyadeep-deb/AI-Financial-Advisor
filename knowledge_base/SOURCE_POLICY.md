# Evidence ingestion policy v1

The registry is a reviewed application artifact, not a user ingestion endpoint.
Only explicitly allowlisted HTTPS hosts, reviewed licences and dated, hashed
versions are eligible. No existing JSON corpus is implicitly approved. Empty
production catalog is intentional until source and distribution rights review.
Expiry is exclusive. A correction or withdrawal supersedes every earlier version;
an unapproved newest version fails closed. Resolve citations again at publication.
Private evidence retains a stable owner across all versions. Generic education
uses curated application text, never instructions or numerical claims from a
document. Topic assignments require human relevance/entailment review.

No source text, questions, owner IDs or URLs enter telemetry; use the existing
metadata-only tracer. Persistence, ingestion tooling, licence review workflow,
private document lifecycle hooks and semantic retrieval remain future work.
